# 🏦 Inversiones Martínez - Sistema de Gestión de Préstamos

Sistema profesional desarrollado para la administración de préstamos personales, cobranza y control de capital en tiempo real. Diseñado específicamente para optimizar el flujo de trabajo de **Inversiones Martínez** en Santo Domingo Este.

## 🚀 Características Principales
* **Gestión de Clientes:** Registro y búsqueda rápida por cédula.
* **Modalidades Flexibles:** Soporte para préstamos en **Cuotas Fijas** y modalidad de **Réditos (Interés Fijo)**.
* **Dashboard Inteligente:** Indicadores en tiempo real de Capital en la Calle, Intereses Cobrados e Intereses por Cobrar.
* **Automatización de Documentos:**
    * Generación de **Pagaré Notarial** con fuerza ejecutoria.
    * Tablas de Amortización e Historial de Pagos detallado.
* **Sincronización en la Nube:** Integración total con Google Sheets para almacenamiento seguro y accesible.
* **Recibos Digitales:** Envío automático de recibos de pago vía WhatsApp.

## 🛠️ Tecnologías Utilizadas
* **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+).
* **Backend:** Google Apps Script (GAS).
* **Base de Datos:** Google Sheets API.
* **Iconografía:** Font Awesome 6.

## 📈 Lógica Contable Implementada
El sistema utiliza una lógica de **Abono Real al Capital**. 
- En modalidad de **Réditos**, el sistema separa el interés fijo del monto pagado, aplicando únicamente el excedente al saldo pendiente, garantizando un control exacto del capital recuperado.

## 🔐 Seguridad
El acceso al sistema está protegido por un módulo de autenticación administrativa para asegurar que solo personal autorizado pueda gestionar los activos de la empresa.
